Metal Tag to Orchard Position — Planting Checklist

Dedicated field sheet for the Prairie Plants orchard grid

Print setup: Letter (8.5 × 11 in), portrait, 100% scale. Turn off browser headers and footers. Background graphics are optional.

Rows: Start at the south end with R1 and work north toward R15.

Columns: Within each row, start at C1 on the west/windbreak side and work east toward C13.

Match: Use the exact metal Tag ID first. Tree name, code, and inventory row are cross-checks. When one Tag ID covers several trees, use the printed sequence for those otherwise identical trees.

Spot SiteRef: CELL-Eoffset-Soffset locates the listed orchard spot. Offsets are feet east and south from that master cell's northwest corner; B10-E33-S35 is R6-C3. Codes stay with open spots for replacements, not with trees moved outside the orchard. See the master-grid guide.
